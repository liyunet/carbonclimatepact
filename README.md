# Carbon & Climate PACT Africa PLC website

Production-ready static website package for **Carbon & Climate PACT Africa PLC (CCPA)**.

## Structure

- `docs/` — deployment and content documentation
- `functions/` — Cloudflare Pages Functions
- `scripts/` — build and validation scripts
- `site/` — complete production website, logo and image assets
- `.env.example` — environment variable template
- `.gitignore` — Git exclusions
- `package.json` — project scripts and Wrangler dependency
- `wrangler.jsonc` — Cloudflare Pages configuration

## Quick start

```bash
npm install
npm run check
npm run dev
```

## Deploy

```bash
npm run deploy
```

The site is configured for `ccpact.com`. Review `docs/DEPLOYMENT.md` before public launch.
