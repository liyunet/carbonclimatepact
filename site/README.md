# CCPA production-ready website package

This folder contains the complete static website for Carbon & Climate PACT Africa PLC.

## Included
- index.html
- assets/css/style.css
- assets/js/app.js
- assets/images/ccpa-logo.png
- all website photographs in assets/images/
- favicon.ico and PNG icons
- site.webmanifest
- robots.txt
- sitemap.xml
- 404.html

## Deploy
Upload the entire folder contents to the web root of:
- Cloudflare Pages
- Netlify
- GitHub Pages
- cPanel/shared hosting
- any standard static web host

## Contact form
The current contact form uses an email-based fallback. For a public production launch, connect it to a secure form backend if you want server-side submissions.

## Social media
The current social-media controls are website sharing links. Replace them with official CCPA profile URLs after the exact profile addresses are confirmed.

## Domain
The package currently uses https://ccpact.com/ in canonical, social and sitemap metadata. Update these references if a different final domain is used.
