# CCPA production-ready website package

This folder contains the complete static website for Carbon & Climate PACT Africa PLC.

## Included
- index.html
- assets/css/style.css
- assets/js/app.js
- assets/images/ccpa-logo.png
- all website photographs in assets/images/
- favicon.ico and PNG icons
- site.webmanifest
- robots.txt
- sitemap.xml
- 404.html

## Deploy
Uploaded to Cloudflare Pages 

## Domain
The package currently uses https://carbonclimatepact.com/ in canonical, social and sitemap metadata. Update these references if a different final domain is used.
